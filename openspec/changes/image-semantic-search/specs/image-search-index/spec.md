## ADDED Requirements

### Requirement: 非阻塞索引构建

图片索引（向量提取与 OCR）必须（SHALL）在插件宿主主线程之外运行，使插件激活、webview 及其他插件功能无论图片数量多少都保持响应。

#### Scenario: 索引不阻塞激活

- **WHEN** 插件在包含大量图片的工作区中激活
- **THEN** 激活在不运行索引的情况下完成，且在用户触发语义搜索前不发生任何模型下载或推理

#### Scenario: 推理在隔离环境中运行

- **WHEN** 索引正在构建或更新
- **THEN** ONNX 推理与 OCR 在 worker 线程或子进程中执行，插件宿主事件循环不被阻塞（界面持续响应）

#### Scenario: 并发受限

- **WHEN** 索引过程中处理大量图片
- **THEN** 同时处理的图片数量受可配置上限限制，以控制 CPU 与内存占用

### Requirement: 增量索引

系统必须（SHALL）基于文件修改时间增量维护索引：对未变更文件复用已有条目，并移除已删除文件的条目。

#### Scenario: 未变更文件被复用

- **WHEN** 某图片的修改时间与已存储索引条目一致
- **THEN** 系统复用已有向量与 OCR 文本，不重新计算

#### Scenario: 已变更文件被重新计算

- **WHEN** 某图片的修改时间与已存储条目不同（或不存在条目）
- **THEN** 系统重新计算该图片向量与 OCR 文本，并更新索引条目

#### Scenario: 已删除文件被剔除

- **WHEN** 重建时某已索引图片在工作区中已不存在
- **THEN** 其条目从更新后的索引中剔除

### Requirement: 支持格式与 SVG 处理

系统必须（SHALL）索引资源模块所支持的图片格式，并必须在视觉编码前将矢量格式（SVG）光栅化为像素缓冲。

#### Scenario: SVG 在编码前被光栅化

- **WHEN** 索引某个 SVG 图片
- **THEN** 系统将其光栅化为像素缓冲（如 PNG）并将该缓冲送入视觉模型

#### Scenario: 容忍单文件失败

- **WHEN** 某张图片的读取、光栅化、向量提取或 OCR 失败
- **THEN** 跳过该图片并继续处理其余图片

### Requirement: 单工作区索引持久化

索引必须（SHALL）持久化在工作区源码树之外、按工作区作用域存放，且必须（SHALL NOT）被打包进插件。

#### Scenario: 索引跨会话持久化

- **WHEN** 已构建索引后在同一工作区重新打开编辑器
- **THEN** 系统加载已持久化的索引，仅处理变更过的文件

#### Scenario: 索引排除在打包之外

- **WHEN** 插件被打包为 `.vsix`
- **THEN** 包中不包含任何工作区索引文件

### Requirement: 索引进度上报

系统必须（SHALL）向用户上报索引进度。

#### Scenario: 暴露进度

- **WHEN** 索引构建正在处理图片
- **THEN** 系统发出进度更新（如 已处理/总数），可供界面或 VSCode 进度通知消费
